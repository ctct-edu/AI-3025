# デモ04：エージェントで会議資料を準備する

## デモ シナリオ

11 月の品質レビュー会議に向けて、リアドア部品の不具合対策の状況を説明する資料を準備します。議事録、不具合の一覧、取引先の回答の3本から情報を集め、資料の下書きを作る作業を、エージェントに任せます。

このデモは、研修の「第 4 章　AI エージェントと連携する」で扱った公式シナリオ「エージェントを使ってリサーチする」の実演です。単一の作業ではなく「成果」を指定して頼むと、エージェントが複数の手順で取り組みます。仕上げと判断は人が行います。

このデモでは以下のタスクを実施します。

　**タスク１：Researcher に資料の準備を依頼する**

　**タスク２：完成したレポートを確認する**

## 予想時間: 15分（完了までの待ち時間を含む）

## タスク1 - Researcher に資料の準備を依頼する

> **このタスクの目的：** 目標と情報源を伝えて、資料の下書きの作成をエージェントに任せます。

1. Microsoft 365 Copilot アプリ（`https://m365.cloud.microsoft/chat`）の画面左にある「**エージェント**」から「**Researcher**」をクリックします。

   > 注：Researcher が表示されない場合は、ライセンスまたは社内の設定で利用できない可能性があります。その場合は、通常のチャットで同じ文章を送ってお試しください。

2. 入力欄に半角の「**/**」を入力し、次の3本のファイルを1本ずつ指定します。

   | 指定するファイル |
   | ---------------- |
   | 品質対策会議_議事録_20261020 |
   | 不具合一覧_2026年度 |
   | 取引先回答_東和精工_20261030 |

3. ファイル名の後ろに続けて、以下の文章を入力して送信します。

   ```
   11 月の品質レビュー会議に向けて、リアドア部品 WS-4471 の不具合対策の状況を説明する資料の下書きを作成してください。状況の要約、件数の推移、主要なリスク、未解決の事項、次のステップを含めてください。
   ```

4. Researcher から追加の質問が表示された場合は、以下のように回答します。

   ```
   品質部長向けに、A4 で 2 ページ程度でお願いします。
   ```

   > 注：レポートが完成するまで、数分から十数分かかる場合があります。画面はそのままにして待ちます。

## タスク2 - 完成したレポートを確認する

> **このタスクの目的：** エージェントが複数の情報源から集めて作った下書きの構成と、参照元を確認します。

1. レポートが完成したら、次の内容が含まれていることを確認します。

   | 項目 | 主な内容 |
   | ---- | -------- |
   | 件数の推移 | 4 月〜10 月の市場クレーム件数と工程内不良率 |
   | 推定原因 | 取付治具の摩耗、取引先の材料変更 |
   | 対策の状況 | 全数目視検査、治具の更新、取引先の暫定対策 |
   | 未解決の事項 | 対策費用の負担割合、市場にある車両への対応範囲 |

2. レポート内の参照番号をクリックし、どのファイルの情報が使われたかを確認します。

   > 注：エージェントが作るのは強力な「たたき台」です。数値や結論は原文で確かめ、自分の判断を加えてから共有します（デモ05 で確認の方法を試します）。

以上で本デモは完了です。
