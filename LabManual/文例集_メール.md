# メールの文例集

デモ05〜07・18 で使った頼み方を、よくある場面ごとにまとめました。〔　〕の部分を書き換えて使います。

> どの場面でも、**日付・金額・原因などの事実は自分で書いて渡す**のが基本です。AI に任せるのは「文章にすること」だけです。

## お詫びする

```
〔相手〕へのお詫びメールを作成してください。言い訳はせず、事実・原因・今後の対応の順で、誠実かつ簡潔に。事実は次のとおりです。
・〔何が起きたか〕
・〔原因〕
・〔今後の対応・再発防止策〕
```

## 断る

```
〔相手〕からの〔依頼の内容〕に、角を立てずに断る返信を 3 パターン作ってください。〔断る理由〕と、〔代わりに出せるもの〕を伝えてください。
```

## 催促する

```
〔相手〕に、〔期限を過ぎているもの〕の提出をお願いするメールを作ってください。責める言い方にならないように、新しい期限を〔日付〕として伝えてください。
```

## 日程を調整する

```
〔相手〕との打ち合わせの日程を調整するメールを作ってください。候補は〔日時 1〕〔日時 2〕〔日時 3〕です。所要時間は〔○分〕、場所は〔オンライン／会議室〕です。
```

## お礼を伝える

```
〔相手〕に、〔してもらったこと〕へのお礼のメールを作ってください。具体的に何が助かったかを 1 文入れて、3〜4 行に収めてください。
```

## 送る前に確かめる

```
添付は〔相手〕へ送る前の下書きです。〔相手〕の立場で読んで、誤解されそうな表現や失礼に読める表現をすべて指摘してください。表現ごとに「なぜまずいか」と「言い換え案」を表にしてください。
```

```
この下書きは、相手の質問〔質問 1〕〔質問 2〕にすべて答えていますか？答えていないものがあれば教えてください。
```
