# デモ03：根拠の有無で回答を比べる

## デモ シナリオ

取引先との打ち合わせに向けて、リアドア部品の不具合対策の状況報告を Copilot に作ってもらいます。同じ依頼文を、ファイルを指定しない場合と指定した場合の2回送り、回答を比べます。

このデモは、研修の「第 3 章　根拠づけが重要な理由」で扱った公式シナリオ「業務に基づく」の実演です。回答の質を決めるのは、言い回しよりも、AI が参照できる情報（根拠）です。

このデモでは以下のタスクを実施します。

　**タスク１：ファイルを指定せずに依頼する**

　**タスク２：ファイルを指定して同じ依頼をする**

　**タスク３：2つの回答を比べる**

## 予想時間: 10分

## タスク1 - ファイルを指定せずに依頼する

> **このタスクの目的：** 根拠となる情報を渡さないと、どのような回答になるかを確認します。

1. Microsoft 365 Copilot アプリ（`https://m365.cloud.microsoft/chat`）で、画面左上の「**新しいチャット**」をクリックします。

2. ファイルを指定せずに、以下の文章を入力して送信します。

   ```
   リアドア部品の不具合について、取引先との打ち合わせ用に対策の状況報告を作成してください。現状・対策・未解決の事項・次のステップの順でまとめてください。
   ```

3. 回答が、一般的な報告書のひな形に近い内容になっていることを確認します。

   > 注：Copilot がメールやファイルを自動で検索して参照する場合があります。その場合は、回答の参照元を見て、何を参照したかを確認してください。

## タスク2 - ファイルを指定して同じ依頼をする

> **このタスクの目的：** 根拠となるファイルを渡して、同じ依頼文を送ります。

1. 「**新しいチャット**」をクリックします。入力欄に半角の「**/**」を入力し、次の3本のファイルを1本ずつ指定します。

   | 指定するファイル |
   | ---------------- |
   | 品質対策会議_議事録_20261020 |
   | 不具合一覧_2026年度 |
   | 取引先回答_東和精工_20261030 |

2. ファイル名の後ろに続けて、タスク1と同じ文章を入力して送信します。

   ```
   リアドア部品の不具合について、取引先との打ち合わせ用に対策の状況報告を作成してください。現状・対策・未解決の事項・次のステップの順でまとめてください。
   ```

## タスク3 - 2つの回答を比べる

> **このタスクの目的：** 渡した情報によって回答がどう変わったかを確認します。

1. タスク2の回答に、次のような具体的な内容が入っていることを確認します。

   | 項目 | 主な内容 |
   | ---- | -------- |
   | 現状 | 10 月の市場クレーム 7 件、工程内不良率 1.6％ |
   | 対策 | 全数目視検査、治具の更新（11/15 まで） |
   | 取引先の回答 | 10/28 出荷分から変更前の材料に戻した、対策書は 11/7 提出予定 |
   | 未解決の事項 | 対策費用の負担割合、市場にある車両への対応範囲 |

2. 画面左の履歴からタスク1の回答を開き、タスク2の回答と見比べます。依頼文は同じで、変わったのは AI が参照できた情報だけであることを確認します。

   > 注：回答が一般論に感じたときは、言い回しを変える前に「AI が何を見られたか」を確認します。

以上で本デモは完了です。
