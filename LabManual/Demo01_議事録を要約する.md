# デモ01：議事録を要約する

## デモ シナリオ

出張で3日間不在にしていた間に、品質対策会議が開かれました。戻った翌朝に、会議の内容と自分の担当作業を短時間で把握します。

このデモは、研修の「第 1 章　AI とは」で扱った公式シナリオ「会議を要約する」の実演です。AI は既にある情報（議事録）を整理するのが得意ですが、議事録に書かれていない内容を作り出すわけではありません。要約した結果は、参照元の原文で確かめます。

このデモでは以下のタスクを実施します。

　**タスク１：議事録を指定して要約を依頼する**

　**タスク２：参照元で原文を確認する**

## 予想時間: 5分

## タスク1 - 議事録を指定して要約を依頼する

> **このタスクの目的：** 議事録のファイルを指定し、現状・決定事項・未決事項・担当作業に分けて要約させます。

1. Microsoft 365 Copilot アプリ（`https://m365.cloud.microsoft/chat`）を開きます。画面上部の切り替えが「**職場**」になっていることを確認します。

   > 注：「Web」になっている場合は、「**職場**」をクリックして切り替えます。

2. 入力欄に半角の「**/**」を入力し、候補から「**品質対策会議_議事録_20261020**」をクリックします。

3. ファイル名の後ろに続けて、以下の文章を入力し、**Enter** キーを押して送信します。

   ```
   を要約してください。①不具合の現状 ②決定事項 ③未決事項 ④品質保証部 担当者の作業（期限付き） に分けて、箇条書きでまとめてください。
   ```

4. 回答に、次の内容が含まれていることを確認します。

   | 項目 | 主な内容 |
   | ---- | -------- |
   | 不具合の現状 | 10 月の市場クレーム 7 件、工程内不良率 1.6％（9 月は 0.8％） |
   | 決定事項 | 全数目視検査（10/22 開始）、治具の更新（11/15 まで）、取引先へ経緯報告を依頼（10/31 期限） |
   | 未決事項 | 対策費用の負担割合、市場にある車両への対応範囲 |
   | 担当者の作業 | 市場クレーム車両の対応方針案（10/31）、11 月の品質レビュー資料（11/5） |

   > 注：回答の内容や表現は毎回異なります。上の内容が含まれていれば問題ありません。

## タスク2 - 参照元で原文を確認する

> **このタスクの目的：** 要約の内容が議事録に書かれていることを、参照元で確かめます。

1. 回答の文中や末尾にある参照番号（[1] など）をクリックします。

2. 議事録の該当箇所が表示されることを確認し、要約の数値や期限が原文と一致しているかを確かめます。

   > 注：AI は議事録の内容を整理しただけで、会議の内容を作り出したわけではありません。重要な数値・期限・決定事項は、必ず原文で確認します。

以上で本デモは完了です。
