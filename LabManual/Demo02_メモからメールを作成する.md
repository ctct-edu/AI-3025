# デモ02：メモからメールを作成する

## デモ シナリオ

リアドア部品の納期が遅れることが分かり、生産管理課の課長に状況を報告し、今後の手配を相談する必要があります。手元にあるのは要点のメモだけです。

このデモは、研修の「第 2 章　職場で AI を活用する」で扱った「開始点を作成する」の実演です。要点のメモに、相手・目的・書き方を添えて依頼すると、目的に合った文面の下書きができます。送信する前に、数値と日付は必ず自分で確認します。

このデモでは以下のタスクを実施します。

　**タスク１：Outlook でメールの下書きを作成する**

　**タスク２：下書きを調整する**

　**タスク３：英語のメールを作成する**

## 予想時間: 5分

## タスク1 - Outlook でメールの下書きを作成する

> **このタスクの目的：** 要点のメモから、報告と相談のメールの下書きを作成します。

1. Outlook（`https://outlook.office.com/`）を開き、「**新規メール**」をクリックします。

2. メールの作成画面で、Copilot のアイコンをクリックし、「**Copilot で下書き**」をクリックします。

   > 注：Copilot のアイコンの位置は、画面の幅や Outlook のバージョンによって異なります。

3. 入力欄に以下の文章を貼り付け、「**生成**」をクリックします。

   ```
   生産管理課の課長宛てに、状況報告と相談のメールを作成してください。結論を先に、丁寧かつ簡潔に。要点：リアドア部品 WS-4471 の納期が 11/28 から 12/5 に遅れる／理由は取引先の材料入荷遅れ／在庫で 12/3 まで生産に影響なし／12/3 以降の手配を相談したい
   ```

4. 下書きが表示されたら、件名と本文に次の内容が正しく入っていることを確認します。

   | 項目 | 正しい内容 |
   | ---- | ---------- |
   | 品番 | WS-4471 |
   | 納期 | 11/28 → 12/5 |
   | 生産への影響 | 在庫で 12/3 まで影響なし |

## タスク2 - 下書きを調整する

> **このタスクの目的：** 言い回しを調整し、目的に合った文面に整えます。

1. 下書きの下にある入力欄に以下の文章を入力し、送信します。

   ```
   もっと簡潔にしてください
   ```

2. 文面が短くなったことを確認し、「**保持する**」をクリックして下書きを本文に入れます。

   > 注：練習なので、メールは送信せずに破棄してください。

## タスク3 - 英語のメールを作成する

> **このタスクの目的：** 同じ内容を、海外の担当者宛ての英語のメールにします。

1. 新しいメールで再度「**Copilot で下書き**」を開き、以下の文章を貼り付けて「**生成**」をクリックします。

   ```
   取引先の海外担当者宛てに、英語でメールを作成してください。要点：リアドア部品 WS-4471 の納期が 11/28 から 12/5 に遅れる見込みであることを了解した／12/3 以降の出荷計画を早めに共有してほしい
   ```

   > 注：Outlook に Copilot が表示されない場合は、Microsoft 365 Copilot アプリ（`https://m365.cloud.microsoft/chat`）に同じ文章を入力しても試せます。

2. 英語の下書きが作成されたことを確認します。日付と品番が正しいかを確認したら、メールは送信せずに破棄します。

以上で本デモは完了です。
