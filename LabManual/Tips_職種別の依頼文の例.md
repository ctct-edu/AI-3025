# 依頼文の例（職種別）

研修で紹介した「材料を渡す」「形を決める」「確かめる」の型を使った依頼文の例です。〔　〕の部分をご自身の仕事に合わせて書き換えてください。

## 総務・人事

```
添付の〔就業規則〕の旧版と新版を比べて、変わったところを「条」「旧」「新」「社員が気をつけること」の表にしてください。
```

```
今週届いたメールから、〔年末調整〕について社員から聞かれた質問を一覧にして、よくある質問の順に並べてください。
```

```
添付の〔社内規程〕から、新入社員が間違えやすい点を 4 択クイズにしてください。5 問で、ブラウザで開ける 1 つの HTML ファイルにしてください。
```

## 経理・財務

```
〔経費一覧〕シートで、入力ミスや怪しいデータを探してください。まだ直さないで、「行」「どこがおかしいか」「直し方の案」を表にしてください。
```

```
この集計の合計を、別の方法（全部の行の合計など）で確かめてください。差があれば理由を教えてください。シートは変更しないでください。
```

## 営業

```
〔取引先名〕の〔担当者名〕様から届いたメールを読んで、相手が求めていることと期限だけを箇条書きにしてください。感情的な表現は取り除いてください。
```

```
添付の提案書を、〔反対している部長〕の立場で読んで、突っ込まれそうな点を「指摘」「なぜそう思うか」「答え方の案」の表にしてください。
```

```
今週のメールから、〔案件名〕の状況を上司に報告する文を作ってください。結論を最初に書き、決まったこと・決まっていないこと・困っていることを 3 行で。
```

## 企画・マーケティング

```
〔テーマ〕に取り組んだ日本企業の事例を 3 社調べてください。「何をしたか」「効果（数字があれば）」「注意点」を表にし、出典も付けてください。
```

```
「〔プロジェクト名〕」のメールのやり取りに途中から入りました。これまでに決まったこと（最新の内容）と、私に何を求められているかだけを教えてください。
```

## 情報システム

```
社員からの〔PC の設定〕の質問に答えるエージェントを作りたいです。〔手順書〕だけを根拠にして、手順は番号付きで答えます。手順書に書いていないことは「情報システム部へ問い合わせてください」と案内します。
```

```
このブックの各シートの役割と、式のつながりを、Excel に詳しくない人にも分かるように説明してください。シートは変更しないでください。
```
