# Tips：職種別の依頼文の例

## はじめに

研修で紹介した「依頼の 4 要素」と、職種別の依頼文の例をまとめています。デモ01〜05 を試したあとに、ご自身の業務に合わせて書き換えてお使いください。

> 注：業務の情報を Copilot で扱う場合は、貴社の情報取り扱いルールに従ってください。依頼文の例は講師が作成したもので、特定の企業が使っている依頼文ではありません。

## 依頼の 4 要素

依頼文は、次の 4 つの要素で組み立てます。毎回すべてを書く必要はありません。回答が期待と違ったときに、足りない要素を加えます。

| 要素 | 書くこと | 例 |
| ---- | -------- | -- |
| 目的 | 何をしてほしいか | 10 月の月次報告の概要を作成してください |
| 背景 | なぜ必要か、誰が読むか | 部長会議で報告します。読み手は部長です |
| 期待 | 形式・分量・口調 | 要点 3 つを箇条書きで、各 2 行以内 |
| 情報源 | 参照してほしい情報 | /月次データ と会議の議事録を使用 |

4 つを組み立てると、次のような依頼文になります。

```
10 月の月次報告の概要を作成してください。部長会議で部長に報告します。/月次データ と会議の議事録を参照し、要点 3 つを各 2 行以内の箇条書きでまとめてください。推測した部分には【推測】と付けてください。
```

> 注：「推測した部分には【推測】と付けてください」と加えると、送る前の確認がしやすくなります。

## 事務

| 場面 | 依頼文の例 |
| ---- | ---------- |
| 手順書の作成 | この作業メモから、手順書の下書きを、目的・手順・注意点の形式で作成してください |
| 会議の準備 | /前回の議事録 から、未完了の宿題と担当者を一覧にし、今回の議題案を作成してください |
| 問い合わせへの回答 | /社内規程 を参照し、この問い合わせへの回答案を作成してください。根拠となる条文も示してください |
| データの確認 | この表の重複と入力漏れを見つけ、修正が必要な行を一覧にしてください |

## 工場（現場）

| 場面 | 依頼文の例 |
| ---- | ---------- |
| シフトの引き継ぎ | 今日のシフトのメモを、次のシフト向けの引き継ぎ報告にまとめてください |
| 手順書を読みやすくする | この作業手順を、初めて担当する人にも分かる短い文に書き直してください |
| 保守手順を探す | /設備マニュアル から、定期点検の手順と注意点を探して箇条書きにしてください |
| 報告書の作成 | このメモから、ヒヤリハット報告書の下書きを、発生状況・原因・対策の順に作成してください |

## 製造（開発・品質）

| 場面 | 依頼文の例 |
| ---- | ---------- |
| 要求の整理 | この要求仕様から、関連する社内標準の項目と、重複している要求を挙げてください |
| 不具合の報告 | /不具合メモ を元に、現象・原因・対策・再発防止の順で報告書の下書きを作成してください |
| データの分析 | この表から、不良率が増えている項目を挙げ、推移をグラフにしてください |
| 変更の周知 | この変更内容から、影響を受ける部署と対応事項を整理し、通知文の下書きを作成してください |

## 販売

| 場面 | 依頼文の例 |
| ---- | ---------- |
| メールの要約 | このお客様とのメールのやり取りを要約し、未回答の質問と次の行動を挙げてください |
| 商談の準備 | /前回の商談メモ と /提案資料 から、今回の商談で確認すべき点を 5 つ挙げてください |
| 提案書の作成 | /製品資料 を参照し、お客様の課題に合わせた提案書の構成案を作成してください |
| お礼のメール | 本日の打ち合わせのお礼と、決まった次の行動を伝えるメールを、丁寧かつ簡潔に作成してください |

## 送る前に確認する 6 つの観点

Copilot の回答は下書きです。共有する前に、次の観点で確認します。

| 観点 | 確認すること |
| ---- | ------------ |
| 正確さ | 数値・日付・名称が原文と一致しているか |
| 最新か | 古い資料や改訂前の情報を参照していないか |
| 出典 | 参照元に書かれていない内容が足されていないか |
| 抜け漏れ | 重要な事実、例外、未決の事項が落ちていないか |
| 読み手 | 相手と目的に合った内容・言葉遣いか |
| 機密 | 送ってはいけない情報が混ざっていないか |
