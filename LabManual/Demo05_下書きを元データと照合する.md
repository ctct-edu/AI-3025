# デモ05：下書きを元データと照合する

## デモ シナリオ

AI が作った品質レビュー資料の下書きを、上司に送る前に確認します。練習用データの「品質レビュー資料_下書き.docx」には、確認の練習のために誤りを3点入れてあります。

このデモは、研修の「第 5 章　自信を持って AI を使用する」で扱った公式シナリオ「AI によって生成されたコンテンツを管理する」の実演です。確認の作業にも Copilot を使えますが、Copilot の指摘も下書きです。最後は人が原データで確かめます。

このデモでは以下のタスクを実施します。

　**タスク１：自分で下書きを読む**

　**タスク２：Copilot に元データと照合させる**

　**タスク３：原データで確かめて答え合わせをする**

## 予想時間: 10分

## タスク1 - 自分で下書きを読む

> **このタスクの目的：** Copilot に頼る前に、自分の目で下書きを確認します。

1. OneDrive の「**AI-3025練習**」フォルダーで「**品質レビュー資料_下書き.docx**」を開きます。

2. 下書きを読み、おかしいと思う箇所をメモします。

   > 注：次の 6 つの観点で確認すると、誤りを見つけやすくなります。

   | 観点 | 確認すること |
   | ---- | ------------ |
   | 正確さ | 数値・品番・日付が原文と一致しているか |
   | 最新か | 古い資料や改訂前の情報を参照していないか |
   | 出典 | 参照元に書かれていない内容が足されていないか |
   | 抜け漏れ | 重要な事実、例外、未決の事項が落ちていないか |
   | 読み手 | 相手と目的に合った内容・言葉遣いか |
   | 機密 | 送ってはいけない情報が混ざっていないか |

## タスク2 - Copilot に元データと照合させる

> **このタスクの目的：** 下書きと元データの不一致や抜けを、Copilot に一覧にさせます。

1. Microsoft 365 Copilot アプリ（`https://m365.cloud.microsoft/chat`）で「**新しいチャット**」をクリックします。入力欄に半角の「**/**」を入力し、次の3本のファイルを1本ずつ指定します。

   | 指定するファイル |
   | ---------------- |
   | 品質レビュー資料_下書き |
   | 不具合一覧_2026年度 |
   | 取引先回答_東和精工_20261030 |

2. ファイル名の後ろに続けて、以下の文章を入力して送信します。

   ```
   品質レビュー資料_下書き の内容を、不具合一覧_2026年度 と 取引先回答_東和精工_20261030 と照合してください。数値・日付の不一致と、反映されていない重要な情報を表にしてください。
   ```

3. 不一致と抜けが表の形で一覧になっていることを確認します。

## タスク3 - 原データで確かめて答え合わせをする

> **このタスクの目的：** Copilot の指摘が正しいかを原データで確かめ、仕込んだ誤りと照らし合わせます。

1. OneDrive で「**不具合一覧_2026年度.xlsx**」と「**取引先回答_東和精工_20261030.docx**」を開き、Copilot が指摘した箇所を原文で確認します。

2. タスク1の自分のメモと、Copilot の指摘を、次の答えと照らし合わせます。

   | 項目 | 下書きの記載 | 正しい内容 | 根拠 |
   | ---- | ------------ | ---------- | ---- |
   | 10 月の市場クレーム | 9 件 | 7 件 | 不具合一覧の月別推移と明細 |
   | 10 月の工程内不良率 | 1.2% | 1.6%（82 ÷ 5,100） | 不具合一覧の月別推移 |
   | 取引先の回答 | 「回答待ち」 | 10/30 に回答済み。10/28 出荷分から変更前の材料に戻し、対策書は 11/7 提出予定。費用の負担は別途協議 | 取引先回答 |

   > 注：Copilot の指摘も「下書き」です。指摘が正しいかを原データで確かめ、自分の所見を加えてから共有するのは人の役割です。

以上で本デモは完了です。
